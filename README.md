# Personal Scripts — 青龙面板每日签到脚本合集

面向 **青龙面板(Qinglong)** 的每日签到自动化脚本合集,覆盖 **网易云音乐、什么值得买、爱奇艺、139云盘** 等多个平台的自动签到与每日权益领取。脚本优先使用 Python 标准库,凭据一律取自环境变量,支持多账号与通知推送(青龙内置 / PushPlus / Server酱)。

## 脚本列表

| 脚本 | 说明 | cron |
|---|---|---|
| `139_yunduo.py` | 中国移动云盘(139云盘)云朵任务自动执行 | `0 9 * * *` |
| `netease_music_checkin.py` | 网易云音乐每日签到(weapi 接口,自动判断重复) | `15 9 * * *` |
| `smzdm_checkin.py` | 什么值得买每日签到(md5 签名,自动判断重复) | `30 9 * * *` |
| `iqiyi_checkin.py` | 爱奇艺每日签到+抽奖(双签到接口,md5 签名) | `5 10 * * *` |

### 功能特性

- **多平台覆盖**:网易云音乐云贝签到、什么值得买积分签到、爱奇艺自然月签到+积分签到+会员抽奖、139云盘云朵任务
- **每日自动运行**:各脚本 cron 已错开(9:00 / 9:15 / 9:30 / 10:05),避免青龙并发触发
- **自动去重**:签到成功 / 今日已签到 / Cookie 失效 自动识别
- **多账号支持**:环境变量多账号(每行一条 Cookie / token),自动轮询
- **通知推送**:青龙内置通知 → PushPlus → Server酱,按优先级自动选择
- **纯标准库优先**:仅网易云需要 pycryptodome(AES 加密),其余脚本零第三方依赖
- **凭据安全**:全部从环境变量读取,日志自动脱敏(mask_cookie),不落盘不硬编码

> 各脚本的环境变量、依赖、凭据(token/Cookie)获取方法,均写在**各脚本开头注释**中,请直接查看脚本头部。

## 青龙面板配置(仓库订阅)

在青龙面板 **订阅管理** 中添加(推荐,可自动更新 + 自动建任务):

```
ql repo https://github.com/deeplee/personal-scripts.git "*.py" "" ""
```

- 第 1 个引号参数 `*.py` = 拉取仓库全部脚本(白名单正则;若只想拉单个脚本可写 `139_yunduo.py`)
- 第 2、3 个引号参数 = 排除规则、依赖文件(留空;netease 脚本需在青龙依赖管理中安装 `pycryptodome`)
- 添加后青龙会自动 `git clone` 到脚本目录,并按脚本头部的 `# cron:` 注释**自动创建定时任务**(任务名取自 `# new Env('...')`),后续 `git pull` 更新时任务自动同步
- 各脚本 cron 已错开,避免青龙同时并发触发

定时任务已由订阅自动生成;如需调整时间,编辑任务修改 cron 表达式即可。

## 本机运行

```bash
python3 139_yunduo.py              # 凭据来自环境变量
python3 netease_music_checkin.py   # 凭据来自环境变量
```

无凭据时脚本以退出码 1 结束(未配置账号)。
